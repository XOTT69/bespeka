# Безпека — укриття Києва та Київської області

PWA-карта укриттів для швидкого пошуку найближчої точки.

## Джерела
- Офіційний ArcGIS API Департаменту муніципальної безпеки Києва.
- OpenStreetMap / Overpass API — додаткові точки по Київській області.
- Офіційна загальноукраїнська карта ДСНС для звірки: https://shelters.dsns.gov.ua/

> OpenStreetMap не є офіційним реєстром. У застосунку джерело показується для кожної точки.

## Можливості
- інтерактивна карта та кластеризація;
- пошук і фільтри;
- геолокація та сортування за відстанню;
- маршрут через Google Maps;
- фото, якщо в джерелі є пряме посилання або Wikimedia Commons;
- локальний кеш останнього успішного завантаження;
- встановлення як PWA;
- GitHub Pages deploy через Actions.

## GitHub Pages
Workflow у `.github/workflows/pages.yml` публікує статичний сайт з гілки `main`.

Якщо Pages ще не активований автоматично: Repository → Settings → Pages → Source → **GitHub Actions**, після чого перезапусти workflow.
